# 通知服务和合同服务 - 快速启动指南

## 📦 项目概述

本次开发完成了**通知服务**和**合同服务**的完整实现:

### ✅ 通知服务 (端口: 8091)
- 站内消息发送
- 消息模板管理(支持变量替换)
- 未读消息查询
- RocketMQ异步消息处理

### ✅ 合同服务 (端口: 8092)
- 根据订单自动生成合同
- 在线确认签署功能
- 合同状态管理和查询
- 合同文件下载

## 🚀 快速启动(3步)

### 步骤1: 初始化数据库

**由于PowerShell执行策略限制,请手动执行SQL**:

1. 打开MySQL命令行
```bash
mysql -u root -p
```

2. 输入密码后,执行以下SQL(复制粘贴):

```sql
-- 创建通知服务数据库
CREATE DATABASE IF NOT EXISTS apartment_notification DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE apartment_notification;

-- 创建消息表
CREATE TABLE IF NOT EXISTS `notification_message` (
  `id` BIGINT NOT NULL AUTO_INCREMENT PRIMARY KEY,
  `user_id` BIGINT NOT NULL,
  `type` VARCHAR(50) NOT NULL,
  `title` VARCHAR(200) NOT NULL,
  `content` TEXT NOT NULL,
  `biz_id` BIGINT DEFAULT NULL,
  `is_read` TINYINT NOT NULL DEFAULT 0,
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `read_at` DATETIME DEFAULT NULL,
  KEY `idx_user_id` (`user_id`),
  KEY `idx_type` (`type`),
  KEY `idx_is_read` (`is_read`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 创建模板表
CREATE TABLE IF NOT EXISTS `notification_template` (
  `id` BIGINT NOT NULL AUTO_INCREMENT PRIMARY KEY,
  `code` VARCHAR(100) NOT NULL UNIQUE,
  `name` VARCHAR(200) NOT NULL,
  `type` VARCHAR(50) NOT NULL,
  `title_template` VARCHAR(200) NOT NULL,
  `content_template` TEXT NOT NULL,
  `enabled` TINYINT NOT NULL DEFAULT 1,
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY `uk_code` (`code`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 插入默认模板
INSERT INTO `notification_template` (`code`, `name`, `type`, `title_template`, `content_template`) VALUES
('ORDER_CREATED', '新订单通知', 'ORDER', '您收到了一个新的订单', '您的房源【{{houseName}}】收到了新订单，订单号：{{orderNo}}'),
('ORDER_PAID', '订单支付成功', 'ORDER', '订单支付成功', '订单{{orderNo}}已成功支付'),
('PAYMENT_SUCCESS', '支付成功', 'PAYMENT', '支付成功', '订单{{orderNo}}支付成功，金额：¥{{amount}}元'),
('CONTRACT_CREATED', '合同生成', 'CONTRACT', '租赁合同已生成', '合同{{contractNo}}已生成，请及时签署');

-- 创建合同服务数据库
CREATE DATABASE IF NOT EXISTS apartment_contract DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE apartment_contract;

-- 创建合同表
CREATE TABLE IF NOT EXISTS `contract` (
  `id` BIGINT NOT NULL AUTO_INCREMENT PRIMARY KEY,
  `contract_no` VARCHAR(100) NOT NULL UNIQUE,
  `order_id` BIGINT NOT NULL,
  `landlord_id` BIGINT NOT NULL,
  `tenant_id` BIGINT NOT NULL,
  `house_id` BIGINT NOT NULL,
  `house_name` VARCHAR(200) NOT NULL,
  `house_address` VARCHAR(500) DEFAULT NULL,
  `rental_amount` DECIMAL(10,2) NOT NULL,
  `deposit_amount` DECIMAL(10,2) DEFAULT 0,
  `start_date` DATE NOT NULL,
  `end_date` DATE NOT NULL,
  `status` VARCHAR(50) NOT NULL DEFAULT 'PENDING',
  `file_path` VARCHAR(500) DEFAULT NULL,
  `landlord_signed_at` DATETIME DEFAULT NULL,
  `tenant_signed_at` DATETIME DEFAULT NULL,
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY `uk_contract_no` (`contract_no`),
  KEY `idx_order_id` (`order_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 创建签署记录表
CREATE TABLE IF NOT EXISTS `contract_signature` (
  `id` BIGINT NOT NULL AUTO_INCREMENT PRIMARY KEY,
  `contract_id` BIGINT NOT NULL,
  `user_id` BIGINT NOT NULL,
  `user_type` VARCHAR(20) NOT NULL,
  `signature_data` TEXT DEFAULT NULL,
  `ip_address` VARCHAR(50) DEFAULT NULL,
  `signed_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  KEY `idx_contract_id` (`contract_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

SELECT '✓ 数据库初始化完成!' AS message;
```

### 步骤2: 创建文件存储目录

Windows PowerShell:
```powershell
New-Item -ItemType Directory -Path "D:\apartment\contracts" -Force
```

### 步骤3: 启动通知服务

**终端1 - 启动通知服务**:
```bash
cd apartment-notice-service
mvn spring-boot:run
```

等待启动完成(看到 "🚀 通知服务启动成功! 端口: 8091")

**终端2 - 启动合同服务**:
```bash
cd apartment-contract-service
mvn spring-boot:run
```

等待启动完成(看到 "📝 合同服务启动成功! 端口: 8092")

## 🔧 配置说明

### 通知服务配置 (application.yml)

```yaml
server:
  port: 8091  # 端口

spring:
  datasource:
    url: jdbc:mysql://localhost:3306/apartment_notification  # 数据库
    username: root
    password: 123456

rocketmq:
  name-server: 192.168.124.29:9876  # RocketMQ地址
```

### 合同服务配置 (application.yml)

```yaml
server:
  port: 8092  # 端口

spring:
  datasource:
    url: jdbc:mysql://localhost:3306/apartment_contract  # 数据库
    username: root
    password: 123456

contract:
  file:
    base-path: D:/apartment/contracts  # 合同文件存储路径
```

## ⚠️ 常见问题

### Q: RocketMQ连接失败?
A: 暂时不影响使用,可以使用HTTP直接调用通知服务API

### Q: 数据库连接失败?
A: 检查MySQL是否启动,用户名密码是否正确

### Q: 合同文件路径错误?
A: 修改 `application.yml` 中的 `contract.file.base-path`
